# Sign-in code emails: Resend as Auth0's email provider

Why: Auth0's built-in sender signs with its own domain, so DMARC fails for the `From` address and Gmail files the code in spam (#86). A provider that signs with `checkmateprep.com` fixes that. Resend is the choice (free plan: 3,000 emails/month, 100 a day; Pro is $20/month for 50,000).

This page never holds an API key. The key lives in Auth0 (Branding → Email Provider) and in the password manager.

## 1. Add the domain in Resend

1. Resend → **Domains → Add Domain**: `checkmateprep.com`. Choose the region closest to most users (US East is the default).
2. Resend then shows three records with the exact values. Copy them from there; they are per account.

## 2. DNS records in Cloudflare

Cloudflare → `checkmateprep.com` → **DNS → Records → Add record**. Enter only the name, not the full domain. **All of these must be DNS only (grey cloud).**

| Type | Name | Value | Priority | What it is |
| --- | --- | --- | --- | --- |
| MX | `send` | the MX value from Resend (looks like `feedback-smtp.<region>.amazonses.com`) | 10 | Return path (bounces) for the `send` subdomain |
| TXT | `send` | the SPF value from Resend (looks like `v=spf1 include:amazonses.com ~all`) | | SPF for the return path |
| TXT | `resend._domainkey` | the DKIM key from Resend (`p=…`) | | DKIM: signs the message as `checkmateprep.com` |
| TXT | `_dmarc` | `v=DMARC1; p=none; rua=mailto:<reports address>` | | DMARC policy (see below) |

Notes:
- The MX and SPF records are on the `send` **subdomain**, so they don't clash with Cloudflare Email Routing's MX and SPF on the root domain (#61).
- Don't add a second SPF record on the root; there can only be one there.
- DMARC: start with `p=none` (report only). Once the reports show nothing but Resend and Email Routing, raise it to `p=quarantine`, later `p=reject`. Use `privacy@checkmateprep.com` for `rua` (a role address, not a personal one).
- Back in Resend, press **Verify DNS Records**. It is usually minutes, up to 72 hours.

## 3. Resend settings

- **API key:** Resend → API Keys → Create, permission **Sending access**, limited to the `checkmateprep.com` domain. Keep it for step 4 only.
- **Tracking:** on the domain, turn **open tracking** and **click tracking** off (tracking pixels and rewritten links are spam signals for a code email).

## 4. Auth0

1. **Branding → Email Provider** → turn on **Use my own email provider** → **Resend**.
2. Paste the API key.
3. **From address:** `no-reply@checkmateprep.com`. It must not be an `auth0.com` address, or Auth0 keeps sending its default template.
4. Save, then **Send test email**.

## 5. The code email template

**Authentication → Passwordless → Email → Settings** (Syntax: **Liquid**).

- **From:** `Checkmate Prep <no-reply@checkmateprep.com>`
- **Subject:** `Your Checkmate Prep sign-in code`
- **Message:**

```html
<!DOCTYPE html>
<html lang="en">
<head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1"></head>
<body style="margin:0;padding:24px;background:#f1f3ef;font-family:-apple-system,BlinkMacSystemFont,'Segoe UI',Roboto,Helvetica,Arial,sans-serif;color:#1a2a22;">
  <div style="max-width:420px;margin:0 auto;background:#ffffff;border:1px solid #dfe5df;border-radius:12px;padding:28px;">
    <p style="margin:0 0 12px;font-size:16px;font-weight:600;">Checkmate Prep</p>
    <p style="margin:0 0 16px;font-size:15px;line-height:1.5;">Your sign-in code:</p>
    <p style="margin:0 0 20px;font-size:30px;letter-spacing:6px;font-weight:700;font-family:ui-monospace,Menlo,Consolas,monospace;">{{ code }}</p>
    <p style="margin:0 0 8px;font-size:14px;line-height:1.5;color:#4a5a52;">Enter it where you asked to sign in. It works once and expires soon.</p>
    <p style="margin:0;font-size:13px;line-height:1.5;color:#6b7a72;">Didn't ask for this? You can ignore this email; nobody can sign in without the code.</p>
  </div>
</body>
</html>
```

Notes: the app name is written out ("Checkmate Prep"), not `{{ application.name }}`, because the iOS application is named "Checkmate Prep iOS". No images or links, which also keeps spam scores low. The plain-text part is generated by Auth0.

## 6. Check it worked

Request a code to a Gmail address and open **Show original**. Expected:

```
dkim=pass header.i=@checkmateprep.com
spf=pass … smtp.mailfrom=…@send.checkmateprep.com
dmarc=pass … header.from=checkmateprep.com
```

Then try Outlook/Hotmail and iCloud, and note where each one landed in the issue.
